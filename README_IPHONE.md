# Facturette iPhone

La version iPhone est une PWA hebergee par GitHub Pages.

Lien prevu apres deploiement :

https://mouyouuu.github.io/facturette/

Installation sur iPhone :

1. Ouvrir le lien dans Safari.
2. Toucher le bouton de partage.
3. Choisir `Ajouter a l'ecran d'accueil`.
4. Lancer `Facturette` depuis l'icone ajoutee.

Les donnees sont stockees localement dans Safari sur l'iPhone. Rien n'est envoye sur un serveur.
